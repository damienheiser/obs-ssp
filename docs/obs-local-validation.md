# Local native OBS validation

The operator authorized building the current plugin against the camera-agent SSP contract, installing it locally, and running real OBS tests with logs. This combines the camera-controls checkpoint and native wire-framing repair. The native connector uses macOS CommonCrypto for the unchanged fixed-profile SHA1 authentication calculation, avoiding an architecture-specific OpenSSL dependency in a universal bundle. Existing non-Apple crypto paths are unchanged. A production-function known-vector check agrees with the prior OpenSSL implementation; one independent read-only review found no backend regression.

The OBS source now propagates the selected camera stream to the native connector, including reconnects and its settings comparison. Camera indices0/1 map to SSP selectors1/2. Switching the subscription does not call the camera format-write API. Camera readback follows the selected subscription instead of the camera default. The stream list intersects camera-reported names with implemented selectors; absent/unrecognized choices are not invented. Bit depth displays only the current selected-stream report, read-only; alternate depths await capability negotiation. Existing explicit camera Apply behavior remains separate. The vendor connector build retains its prior default subscription behavior.

Packet parsing retains the observed bounded extension handling and legacy bodies. No new listener, credentials, firmware writes or camera codec/framerate changes are introduced. The existing four-MiB native packet cap is unchanged; larger future raw frames require an explicit framing/size design. Exact FPS cadence remains30000/1001 and wirePTS microseconds.
