# Media format descriptor requirements

Status: coordination proposal, not a deployed transport schema or availability claim.

Codec1006 means ProRes but does not identify profile, FourCC, coded component depth, chroma or alpha. The actual host fixture demonstrated raw decode falling back to10bit without ap4h; the descriptor must initialize the decoder before first media. The receiver primitive now validates tag/depth combinations and maps actual AVYUV444P12LE to I412. The actual decoded AVFrame remains authoritative for dimensions/pixel format; mismatches must not be silently relabeled.

A versioned descriptor must bind stable stream ID + producer session/clock epoch + positive format generation, with immutable format per generation. Carry codec/FourCC/profile, coded_bits separately from source_valid_bits, chroma, alpha presence, decoded pixel format, exact width/height/rational cadence, PTS/DTS timebase/domain, and color primaries/transfer/matrix/range with explicit unknown values. Describe source conversion declarations and actual coded metadata separately when they disagree. No filename/profile name establishes calibration. Explicit new-format acknowledgment must prevent an older receiver accepting the stream while silently losing precision.

RAW uses a distinct codec/layout descriptor, not ProRes1006 or a gray-video alias. Include CFA/order, packing, byte endianness, valid bit alignment, source bit depth, active geometry/crop, per-plane stride/offset/length, black/white reference levels with calibration status, PTS/timebase and discontinuity. A working Bayer demosaic/color pipeline is required before exposing color video; OBS has no direct Bayer pixel format.

Bounds must be negotiated per ingress: current native C receiver4MiB (camera-server maximum unmeasured), peer16MiB, ProResdetector32MiB, decoder32MP/4slicethreads. A6.1MB access unit fits peer framing but not current native framing. Larger native packets require explicit bounded encoded queues/cancellation and memory acceptance, not simply raising a macro. Transporting the descriptor through negotiated SSP extension versus authenticated/session-bound sideband still needs implementation agreement; do not repurpose unknown fields in the observed20byte extension. Existing capabilities endpoint observations are point-in-time, not a format lease.

Camera mode/controller changes stay with the camera agent and its guarded recovery. This proposal introduces no camera operations or auth surface. Recovery retains legacy42210 reception and rejects unsupported/ambiguous new format rather than advertising it. Tests must use actual tagged payloads, verify precision/plane shape/PTS, exercise descriptor rejection, and observe real source/receiver lifecycle before capability promotion. Host encode/decode speed is not camera real-time support. Video and audio need separate explicit format contracts.
